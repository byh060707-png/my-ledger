# 我的记账本 v2.5

手机优先的人民币 / 卢布双币种个人记账网站，可部署到 GitHub Pages。

## 本版修复
- 本月概览、余额、统计在新增/编辑/删除后立即刷新。
- Safari 返回页面、切换标签页时自动同步本地数据；定时检查其他标签页修改。
- 修复新建账单时账户与币种可能错配的问题。
- 修复账户停用提示反了的问题。
- 修复 CSV 导出重复转义的问题。
- 修复演示数据在零余额账户上无法按批次生成的问题。
- 已有历史账单的分类不能删除，避免破坏历史记录。
- 非信用卡账户默认不允许余额变成负数；信用卡可允许负余额。
- 相同币种转账强制转入=转出；人民币/卢布换汇可按当前汇率自动计算。
- 账单支持按月份、类型、币种、账户、分类、关键词筛选。

## 功能
- CNY / RUB 分开显示
- 多银行、钱包、现金、信用卡账户
- 收入、支出、同币种转账、跨币种换汇
- 编辑、删除账单
- 月预算、分类统计、近半年支出图
- 自定义分类
- JSON 备份 / 恢复、CSV 导出
- 深色模式
- PWA / iPhone 添加到主屏幕

## 数据说明
当前版本把数据保存在浏览器本地 localStorage。GitHub Pages 只负责提供网页，不会自动保存你的账本到云端。换手机前请先导出 JSON 备份。

## 发布
将本目录中的文件上传到 GitHub 仓库根目录，在 Settings → Pages 中选择 `Deploy from a branch`、`main`、`/(root)`。
