# 我的记账本

手机优先的人民币 / 卢布双币种个人记账网站。

## 发布到 GitHub Pages
1. 新建一个 GitHub 仓库，例如 `my-ledger`。
2. 上传本目录全部文件。
3. 打开仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`，Branch 选择 `main`，Folder 选择 `/(root)`，保存。
5. 等待发布完成后，点击 `Visit site`。GitHub Pages 官方说明发布可能需要几分钟。

## iPhone 使用
用 Safari 打开网站 → 分享 → 添加到主屏幕 → 添加。

## 数据
当前版本数据保存在浏览器本地。网站本身可以在线访问，但还没有账号/云数据库同步。请定期使用“设置 → 数据管理 → 导出 JSON”备份。

## 功能
- CNY / RUB 双币种
- 多银行、钱包、现金账户
- 收入 / 支出 / 同币种转账 / 跨币种换汇
- 账单编辑、删除、搜索、筛选
- 月度统计、分类统计、近半年趋势、预算
- 自定义分类
- JSON 备份 / 恢复、CSV 导出
- 深色模式
- PWA manifest、图标、离线缓存
