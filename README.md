# 我的记账本 v2.9

手机优先的多币种个人记账 PWA。

## 主要功能
- CNY 基础币种，可启用 RUB、USD、EUR、GBP、JPY、KRW、HKD、SGD、THB、AED、KZT、CAD、AUD、CHF、SEK、NOK、DKK、PLN、TRY、NZD、MYR、IDR、INR、VND、PHP 等。
- 可以自己新增任意 3-5 位币种代码、名称、符号、旗帜和小数位。
- 所有汇率统一按“1 CNY = X 目标币种”填写。
- 支持当前汇率、按日期设置历史汇率、跨币种换汇。
- 历史账单保存自己的汇率，不会因修改当前汇率而改变。
- 多银行/钱包/现金/银行卡账户。
- 收入、支出、转账、换汇、搜索、统计、预算、备份恢复。
