我的记账本 v2.0

主要功能
- 人民币 CNY / 卢布 RUB 双币种，首页分开显示余额
- 多账户：银行、电子钱包、现金、银行卡/信用卡、其他
- 收入、支出、同币种转账、跨币种换汇
- 账单编辑与删除
- 搜索、月份、类型、币种筛选
- 月度收入/支出/分类统计，近半年支出柱状图
- 月预算与进度条
- 自定义分类
- JSON 完整备份 / 导入，CSV 导出
- 深色模式
- 有历史账单的账户可停用，不会破坏历史记录
- PWA 图标、manifest、离线缓存

使用说明
1. 直接打开 index.html 可以使用核心记账功能。
2. 想在手机上“添加到主屏幕”并使用离线缓存，请部署到 HTTPS 网站，或使用本机 HTTP 服务，不要用 file:// 作为正式部署方式。
3. 数据默认保存在当前浏览器。换手机、清理浏览器数据前，请先导出 JSON 备份。
4. 默认汇率为 1 CNY = 11 RUB，可在设置中修改；此汇率用于总资产折算和统计，不会修改已记录的实际账单金额。
